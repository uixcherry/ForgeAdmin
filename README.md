# 🛡️ Инструкция Модератора (Forge.Admin)

Руководство по использованию команд администрирования.

## ❗ Золотые правила
1. **Всегда указывайте причину.** Игрок должен понимать, за что наказан.
2. **Проверяйте SteamID.** Ошибка в одной цифре = бан невиновного.
3. **Думайте перед Enter.** Команды срабатывают мгновенно.

---

## 📋 Команды

### 🚫 Бан

| Команда | Описание |
|:--------|:---------|
| `/ban <игрок\|steamid> <время> [причина] [-wipe] [-silent]` | Забанить игрока |
| `/ban info <steamid>` | Информация о бане |
| `/ban list` | Список активных банов (до 10) |
| `/ban -confirm` | Подтвердить бан с вайпом |
| `/unban <steamid>` | Снять бан |

**Флаги:**
- `-wipe` — удаляет все постройки игрока (только для perm бана, требует permission `forge.admin.ban.wipe`)
- `-silent` — тихий бан без уведомления в глобальный чат (Discord уведомление остаётся, требует permission `forge.admin.ban.silent`)

**Особенности:**
- Поддерживает бан оффлайн игроков по SteamID
- Если игрок уже забанен — команда сообщит об этом
- Бан с `-wipe` требует подтверждения через `/ban -confirm` (таймаут настраивается в конфиге)

**Примеры:**
```
/ban Alex 1d Оскорбление
/ban 76561198000000000 perm Читы
/ban Alex perm Читы -wipe
/ban Alex 1d Нарушение -silent
/ban Alex perm Серьёзное нарушение -wipe -silent
/ban info 76561198000000000
/ban list
/unban 76561198000000000
```

### 👢 Кик

| Команда | Описание |
|:--------|:---------|
| `/kick <игрок> [причина]` | Кикнуть игрока |

> Работает только для онлайн игроков.

**Пример:**
```
/kick Alex Смените никнейм
```

---

### 🔇 Мут

| Команда | Описание |
|:--------|:---------|
| `/mute <игрок> <время> [причина] [-v\|-voice]` | Замутить игрока |
| `/mute info <игрок\|steamid>` | Информация о муте |
| `/unmute <игрок>` | Снять мут |

**Флаги:**
- `-v` или `-voice` — дополнительно мутит голосовой чат

**Ограничения:**
- Перманентный мут недоступен — максимальная длительность ограничена `MaxMuteMinutes` в конфиге
- Работает только для онлайн игроков

**Примеры:**
```
/mute Alex 30m Спам
/mute Alex 1h Оскорбления -v
/mute Alex 2h Токсичность -voice
/mute info Alex
/mute info 76561198000000000
/unmute Alex
```

### ⚠️ Предупреждения (Варны)

| Команда | Описание |
|:--------|:---------|
| `/warn <игрок\|steamid> [время] <причина>` | Выдать варн (время опционально) |
| `/warn info <игрок\|steamid>` | Список активных варнов игрока |
| `/unwarn <steamid> <id>` | Снять конкретный варн по ID |
| `/unwarnall <steamid>` | Снять все варны |

**Время:**
- Если указано — варн действует указанный период
- Если не указано — используется `DefaultWarnMinutes` из конфига (0 = постоянный)
- Максимум: `MaxWarnMinutes` (по умолчанию 7 дней)

**Особенности:**
- Поддерживает выдачу варнов оффлайн игрокам по SteamID

**Примеры:**
```
/warn Alex 1h Флуд в чате
/warn Alex 7d Серьёзное нарушение
/warn Alex perm Обход бана
/warn Alex Нецензурная брань
/warn 76561198000000000 1d Нарушение правил
/warn info Alex
/warn info 76561198000000000
/unwarn 76561198000000000 15
/unwarnall 76561198000000000
```

**Как узнать ID варна:** Используйте `/warn info` — показывает `#ID`, время выдачи, модератора, срок истечения и причину.

## ⏱️ Формат времени

| Код | Значение | Пример |

## �🔒 Автоматические системы

### Обход бана (Ban Evasion)
Система автоматически обнаруживает попытки обхода бана через смену аккаунта (по IP и HWID).

**Что происходит:**
1. Новый аккаунт автоматически банится
2. Уведомление в чат сервера
3. Уведомление в Discord с информацией об оригинальном аккаунте

Игроки из списка `IPBanBypassList` в конфиге исключены из проверки.

## 💡 Полезные советы

- **Сложный ник?** Используйте SteamID вместо имени игрока
- **Ошиблись с баном?** Сразу `/unban <SteamID>` и выдайте заново
- **Проверить статус игрока?** `/ban info`, `/mute info`, `/warn info`
- **Оффлайн наказания:** Бан и варн работают по SteamID, мут и кик — только онлайн
