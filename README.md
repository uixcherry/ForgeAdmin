# 🛡️ Инструкция Модератора (Forge.Admin)

Руководство по использованию команд администрирования.

## ❗ Золотые правила
1. **Всегда указывайте причину.** Игрок должен понимать, за что наказан.
2. **Проверяйте SteamID.** Ошибка в одной цифре = бан невиновного.
3. **Думайте перед Enter.** Команды срабатывают мгновенно.

---

## 📋 Команды

### 🚫 Бан

| Команда | Описание |
|:--------|:---------|
| `/ban <игрок\|steamid> <время> [причина]` | Забанить игрока |
| `/ban <игрок\|steamid> perm [причина] -wipe` | Перм-бан с удалением всех построек |
| `/ban -confirm` | Подтвердить wipe |
| `/ban info <steamid>` | Информация о бане |
| `/ban list` | Список активных банов |
| `/unban <steamid>` | Снять бан |

**Флаги:**
- `-wipe` — удаляет все баррикады, структуры и транспорт игрока (только для `perm`)

**Примеры:**
```
/ban Alex 1d Оскорбление
/ban 76561198000000000 perm Читы
/ban Alex perm Дюп -wipe
/ban -confirm
/ban info 76561198000000000
/unban 76561198000000000
```

**⚠️ Использование -wipe:**
1. Требуется право `forge.admin.ban.wipe`
2. Работает только с перманентным баном
3. Требует подтверждения командой `/ban -confirm`
4. Подтверждение действует ограниченное время (см. конфиг)

---

### 👢 Кик

| Команда | Описание |
|:--------|:---------|
| `/kick <игрок> [причина]` | Кикнуть игрока |

**Пример:**
```
/kick Alex Смените никнейм
```

---

### 🔇 Мут

| Команда | Описание |
|:--------|:---------|
| `/mute <игрок> <время> [причина] [-v]` | Замутить игрока |
| `/mute info <игрок>` | Информация о муте |
| `/unmute <игрок>` | Снять мут |

**Флаги:**
- `-v` — дополнительно мутит голосовой чат

**Примеры:**
```
/mute Alex 30m Спам
/mute Alex 1h Оскорбления -v
/mute info Alex
/unmute Alex
```

---

### ⚠️ Предупреждения (Варны)

| Команда | Описание |
|:--------|:---------|
| `/warn <игрок> <причина>` | Выдать варн |
| `/warn info <игрок\|steamid>` | Список всех варнов игрока |
| `/unwarn <steamid> <id>` | Снять конкретный варн по ID |
| `/unwarnall <steamid>` | Снять все варны |

**Примеры:**
```
/warn Alex Нецензурная брань
/warn info Alex
/warn info 76561198000000000
/unwarn 76561198000000000 15
/unwarnall 76561198000000000
```

**Как узнать ID варна:** Используйте `/warn info` — каждый варн имеет номер `#ID`.

---

## ⏱️ Формат времени

| Код | Значение | Пример |
|:----|:---------|:-------|
| `m` | Минуты | `30m` |
| `h` | Часы | `2h` |
| `d` | Дни | `7d` |
| `perm` или `0` | Навсегда | `perm` |

## 🔒 Автоматические системы

### Обход бана (Ban Evasion)
Система автоматически обнаруживает попытки обхода бана через смену аккаунта (по IP).

**Что происходит:**
1. Новый аккаунт автоматически банится
2. Уведомление в чат сервера
3. Уведомление в Discord с информацией об оригинальном аккаунте

Игроки из списка `IPBanBypassList` в конфиге исключены из проверки.

## 🔑 Права доступа

| Право | Описание |
|:------|:---------|
| `forge.admin.ban` | Бан/разбан игроков |
| `forge.admin.ban.wipe` | Использование флага `-wipe` |
| `forge.admin.kick` | Кик игроков |
| `forge.admin.mute` | Мут/размут игроков |
| `forge.admin.warn` | Выдача/снятие варнов |
| `forge.admin.immunity` | Защита от наказаний |

---

## 💡 Полезные советы

- **Сложный ник?** Используйте SteamID или `/players` для списка игроков
- **Ошиблись с баном?** Сразу `/unban <SteamID>` и выдайте заново
- **Проверить статус игрока?** `/ban info`, `/mute info`, `/warn info`
- **Оффлайн наказания:** Бан и варн работают по SteamID, мут — только онлайн
- **Wipe не прошёл?** Проверьте права и используйте только с `perm`

---

## 📡 Discord уведомления

Все действия отправляются в Discord:

- Кики
- Муты / Размуты  
- Варны / Снятие варнов
- Обнаружение обхода бана
